# Requirements and scope
**Functional:** explain three SDLC models; interactive comparison; simulated citizen application and status tracking; synthetic admin dashboard; DevSecOps explanation.
**Non-functional:** runs on a student laptop; no paid dependencies; responsive and keyboard accessible; no real personal data; runs without AWS.
**In scope:** Flask/SQLite app, tests, Docker, Jenkinsfile, SonarQube/Trivy config, Terraform for one EC2 instance.
**Out of scope:** real authentication, real government integration, payments, Kubernetes, HTTPS setup, production hardening.
**Assumptions:** the portal is hypothetical; the model comparison is qualitative and based on the cited literature.
